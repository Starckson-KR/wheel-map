# UI 다듬기 기록 (3순위 1차, 2026-11-11)

기능·데이터·저장값은 바꾸지 않았다(글자 크기 설정 키 `wheelmap.textSize` 하나만 추가). 점검은 Playwright 브라우저(375×812)와 DOM 자동 점검(터치 영역·글자 크기·대비·잘림)으로 했고, 휴대폰 폭·PC 폭, 라이트·다크를 오갔다.

## 1. 고친 것
- **글자 크기 설정 추가**: 설정 시트 "화면 설정"에 글자 크기(보통/크게). `viewPrefs.ts`의 기존 패턴, `<html data-text="large">`가 글자 기준(rem)을 118.75%로 키움. 이를 위해 CSS의 모든 `font-size: Npx`(46곳)와 글자 토큰(`--fs-*`)을 rem으로 바꿈. 크게 상태에서 홈·지도·제보·개선 현황·행정이 가로로 넘치지 않음을 확인.
- **대비(WCAG AA)**: 보조 글자 `--grey-600` #6b7684 → #5d6877(회색 바탕에서 4.19 → 5.1), 채움 버튼 `--blue-600` #2272eb → #1f6de3(4.49 → 4.8), `--green-700` #0f7f55 → #0b6845, 다크 `--blue-700` 추가(행정 "민원 접수" 배지 2.63 → 통과), 채움 버튼 호버색 `--primary-hover` 토큰화. 점검한 화면(홈·제보·알림·내 정보·개선 현황·행정)의 라이트·다크에서 본문 대비 미달 0(지도 축척 막대 제외, 카카오 지도 요소).
- **터치 영역 44px**: 세그먼트·밑줄 탭·진행 칩·알림 칩·랭킹 전환·챌린지·버스 새로고침·사진 버튼은 높이 44. 작은 원형·알약 버튼(닫기 ×, 뒤로, 지도 위 레이어·화면·시연 도구, 길찾기 머리 버튼)은 보이는 크기는 그대로 두고 보이지 않는 터치 영역만 44px로 넓힘. 행정 탭 버튼 너비 44 이상.
- **글자 최소 크기**: 홈 우측 상단 아이콘 라벨 11 → 12px.
- **잘림·줄바꿈**: 지도 위 카드(레이어·화면·시연 도구 버튼이 글자 크게에서 두 줄로 깨짐), 행정 상단(지도로·제목·도구가 겹침), 시연 도구 "+30일"이 두 줄로 깨짐을 고침(줄바꿈 허용 + nowrap).
- **제보 하단 버튼 줄**: 투명 그라데이션 때문에 안내 문구가 목록 위에 겹쳐 보이던 것을 고침(10px 안에 바탕이 차오름).
- **모션**: 색 전환의 `ease`를 모두 `--ease-out`으로 통일(곡선은 `--ease-out`/`--ease-drawer` 두 가지만 남음, 스켈레톤 반짝임은 예외). 릴스 #9 반영. 움직임 줄이기 규칙은 기존 그대로.
- **린트**: `ReportFlow.tsx:91` 사진 id를 모듈 수준 함수 `newPhotoId()`(`crypto.randomUUID`)로 옮김. 동작 같음. 린트 경고는 `scripts/prefetch.ts:687` 하나만 남음.

## 2. 고치지 않은 것(이유)
- 지도 핀·묶음 원(30~36px): 보이지 않는 터치 영역이 이미 따로 있고, 크기를 키우면 지도가 겹침. 범례 안 `♿WC`·`임` 글리프 10~11px는 작은 도형 안 글자라 유지.
- 지도 축척 막대("500m") 10px·대비: 카카오 지도 부품이라 손대지 않음.
- 개발 배지(Development In Progress) 10px: 개발 서버 전용.
- 릴스 #10 화면 전환 규칙(푸시/시트 구분): 코드 규칙만 확인, 별도 변경 없음. 지금 구조(탭 전환=교차, 보조 선택=시트)가 이미 같은 원칙.
- 스낵바 되돌리기(#2): 이전 작업에서 생략된 그대로.
- 시트가 뜰 때 하단 탭 바가 어두워지지 않음: 시트 영역이 탭 바 위쪽에서 끝나는 구조라 가려지는 것은 없어 그대로 둠.

## 3. 2차 다듬기 때 볼 후보
1. 행정 상단(작은 폭·글자 크게에서 3줄)을 "지도로 | 제목" + 도구 줄로 정리하거나 도구를 한 메뉴로 묶기.
2. 홈 아이콘 줄·소식 칩의 가로 스크롤 힌트(끝이 잘려 보이는 정도)와 글자 크게에서 칩 줄바꿈.
3. 시트·카드 안쪽 여백(16/20/24 혼용)을 한 단계 스케일로 통일, 보조 버튼 높이(40/44/52) 정리.
4. PC 폭(1024) 행정·지도 화면 전수 시각 비교(이번엔 폭 375 중심).
5. 글자 크기 "크게"에서 개선 현황 칩·랭킹 줄의 줄바꿈 다듬기, 더 큰 단계(200%) 필요 여부.

## 4. 확인한 것·못 한 것
- 확인: 스켈레톤(우선순위 화면, 자료 요청 3초 지연으로 막대 4개 표시), 카운트 업 중간값(지역 현황 140→215→377→416→432, 움직임 보기 스위치 없이 개발 브라우저에서 확인), 부서별 화면 렌더, 글자 크게 상태의 홈·지도·제보·개선 현황·행정.
- 못 확인: 빈 화면 버튼(시연 데이터가 가득 찬 상태라 빈 화면을 만들지 않음, 초기화 금지 규칙), 사진 이전/다음 버튼(개발 서버 사진이 없음, 코드 존재만 확인), PC 폭(1024) 전 화면 시각 확인, 실제 휴대폰 터치, 내장 브라우저 패널이 300px 폭이라 스크린샷은 Playwright로 대체.
