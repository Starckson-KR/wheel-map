# UX 전수점검 (2026-11-22)

- 본 방법: 개발 서버(`localhost:5173`)를 Playwright로 390×844(일부 360×740), 로그아웃 + 「체험 데이터 채우기」 상태에서 화면을 하나씩 열고 `getBoundingClientRect`·보이는 글자 수·누를 수 있는 요소 수를 잼. 코드는 읽기만 함.
- 숫자 읽는 법: "지도 %"는 화면 높이 844px 중 시트·상단바에 가리지 않은 지도 높이. "조각"은 따로 떨어진 글 덩어리 수, "자"는 공백 뺀 글자 수.
- 주의: 체험 데이터(장애요소 468곳)를 채운 상태라 길 위 장애물 수가 실제보다 많음. 체험 데이터 없이 같은 경로를 잰 값은 확인 못 함.
- 개발 서버에서만 보이는 것(길찾기 입력의 「자체 보행망 / TMAP 비교」 탭, 위쪽 Development 띠)은 문제 목록에서 뺌.

## 1. 한눈 요약

1. **길찾기 결과가 지도를 가림.** 시트 높이가 52%로 고정이라 지도는 44%만 보이고, 시트 첫 화면은 제목·경로 이름·카드 한 장으로 꽉 참. 주된 행동인 「길 안내 시작」은 스크롤해야 나옴. 시트 길이는 경로에 따라 화면 3.4~5.7장.
2. **같은 말을 여러 번 하고 단서 문장을 붙임.** 「치과병원 앞 횡단보도 때문에 돌아가요」는 카드 이름·배지·안내 상자·단계 목록 4곳에 나옴. 「(시민 제보)」는 한 경로에 17번. 제보 상세는 접수번호 2개, 처리기한 경고 2번, 진행 상태 3번, 시연 고지 3번.
3. **핀·제보 상세 시트가 화면의 76%를 덮고, 답이 아래에 있음.** 정류장 상세 1,368px, 제보 상세 1,490px. 「내 제보가 어떻게 됐나」의 답(처리 흐름)은 한 화면 아래(y=711)부터.
4. **지도 상황 칩이 쌓이기만 함.** 칩은 켜고 끄는 방식이라 바꿔 누르면 12px 점이 5색 79개까지 쌓이고 범례는 숨어 있음. 「화장실 찾기」를 눌러도 목록이 없고 시트는 그대로 「장애요소 1곳」.
5. **처음 온 사람이 앱을 보기까지 12화면·최소 17번 누름(코드 기준).** 둘러보기가 없고, 2~3번째 화면이 폰 종류·설치 안내, 4번째는 고를 게 없는 언어 선택(English는 "Coming soon"). 탭 화면도 성격이 다른 것이 섞임(제보 탭 5구역 2,158px, 혜택알림 안에 랭킹·챌린지, 「내 제보」가 3곳).

## 5. 근거 지침

- 닐슨 노먼 그룹, 점진적 공개: 처음에는 꼭 필요한 것만 보이고 나머지는 사용자가 찾을 때 보여 줌. 길찾기 시트·상세 시트를 "기본 한두 줄, 눌렀을 때 자세히"로 바꾸는 근거. https://www.nngroup.com/articles/progressive-disclosure/
- 닐슨 노먼 그룹, 사용성 휴리스틱 8번(간결한 디자인): 관련 없거나 드물게 필요한 정보는 화면에 두지 않음. 군더더기가 필요한 정보의 눈에 띔을 떨어뜨림. 단서 문장·반복 삭제의 근거. 4번(일관성): 다른 낱말이 같은 뜻인지 사용자가 고민하게 하지 않음. 낱말 통일의 근거. https://www.nngroup.com/articles/ten-usability-heuristics/
- 토스 UX 라이팅 8원칙 중 "Weed cutting"(뜻 없는 낱말 지우기), "Remove empty sentences"(뜻 없는 문장·같은 내용 반복 지우기), "Focus on key message"(지금 확인해야 할 것만). https://toss.tech/article/8-writing-principles-of-toss
- Apple HIG·Material의 하단 시트 지침은 원문을 불러오지 못해 인용하지 않음(확인 못 함).

## 6. 화면으로 못 본 것

- 온보딩의 이름·비밀번호·확인·이동 방식·관심·화면·완료(계정을 만들지 않아 코드로만 봄. 누르는 횟수 17은 코드 기준).
- 로그인한 실제 계정의 내 제보 상세(체험 데이터의 「시민 A」 제보로 대신 봄. 기관 번호 입력 칸은 코드로만 봄), 개발자 관리, 행정 화면.
- 제보 제출 뒤 화면(담당 기관 안내·접수 방법), 이웃 제보 넘기기 동작, 설정 동기화.
- 홈 AI 검색 결과 화면(서버 호출이라 입력하지 않음).
- 길 안내 중 지도(자동화 브라우저에서 지도 바탕이 그려지지 않음), 실제 위치를 따라가는 동작.
- 버스 카드(「버스 타고」)를 골랐을 때의 화면, R2의 「자세히 보기」 안.
- 체험 데이터 없이 잰 길찾기 결과, 실제 폰(스크롤 막대, 엄지 닿는 범위), 다크 모드 전체(길찾기 결과 한 화면만 봤고 눈에 띄는 문제 없었음), 설치 안내의 아이폰 쪽, 개인정보 안내·이용 안내는 문구만 코드로 봄.
