# 공공데이터 조사 (광주 북구 용봉동 휠체어 이동경로 지도)

- 조사일: 2026-10-26 / 방식: 공공데이터포털 등 원 출처 페이지 열람(읽기 전용, 키 신청·다운로드 없음)
- 표기: 확인 = 해당 페이지에서 직접 본 내용 / 확인 필요 = 페이지에 없거나 열람 못 함
- 참고: 최근 페이지·데이터 제목에 광주 북구가 `전남광주통합특별시 북구`로 표기됨. 검색·필터 시 구 명칭과 함께 사용할 것.

## 2. 우선 써 볼 만한 것 3개

1. **전국횡단보도표준데이터**: 보도턱낮춤여부·점자블록·음향신호기·폭 등 우리 앱에 바로 필요한 항목이 있고, 북구 레코드가 보임. 단차 cm는 없으나 1차 레이어로 가장 가까움. 파일로 받아 JSON 변환하면 키 노출 문제 없음.
2. **전남광주통합특별시_광주버스정보(광주 BIS) + TAGO 버스도착정보**: 정류소 위치는 광주 BIS, 저상 여부(`vehicletp`)는 TAGO에서 확인됨. 단 광주 BIS의 저상 필드와 TAGO의 광주 지원 여부는 확인 필요. 키는 서버 측·사전 저장 방식으로만 사용.
3. **한국사회보장정보원_장애인편의시설 현황 + 행정안전부_공중화장실정보**: 건물 출입구·경사로·장애인화장실 정보를 얻을 수 있음. 공중화장실은 좌표가 없어 주소 지오코딩 필요, 편의시설 API는 시설 ID 단위 조회라 용봉동 시설 목록 확보 방법 확인 필요.

(보조: 전국교통약자이동지원센터정보 - 광주 센터 정보를 안내 문구로 활용)

## 3. 우리 팀 실측이 여전히 필요한 이유

- 공공데이터는 보도 **유효폭, 경사도, 단차 cm, 포장 상태, 공사·적치물**을 제공하지 못함(횡단보도 표준데이터도 턱낮춤 '여부'만 있음).
- 자료는 연 1회~비정기 갱신이고 일부는 로드뷰 기반 원격 조사라 현재 상태와 다를 수 있으며, 법적 효력 없음(전북 횡단보도 자료 안내문).
- 용봉동 전남대 일대의 보도 구간 단위 정보는 공개 데이터셋을 찾지 못해, 팀 실측이 사실상 유일한 원천임.
