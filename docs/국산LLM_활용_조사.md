# 국산 LLM(EXAONE·Kanana) 활용 조사

조사일 2026-11-11 · 조사만 했고 코드는 수정하지 않음 · 공개 문서만 확인(가입·결제·키 발급 없음)
표기: 「확인 안 됨」은 공식 문서로 확인하지 못했다는 뜻이다. Hugging Face 목록의 수정일은 페이지에 연도가 없는 것이 많아 월·일만 적었다.

## ① 한 줄 결론
- 두 계열 모두 **가중치는 Hugging Face에 공개**돼 있지만, **무료로 아무나 부르는 공식 API는 확인되지 않았다.** 무료 호스팅 API로 풀렸다는 기억은 맞다고 볼 근거를 찾지 못했다.
- **라이선스가 갈린다.** EXAONE(4.5-33B, 4.0-1.2B 등)은 비상업(NC)이라 수업 발표는 가능성이 높지만 앱인토스 출시에는 쓸 수 없다. Kanana는 「자체 서비스 운영」 상업 이용을 허용하되 「Powered by Kanana」 표기 등 조건이 있다.
- 우리 앱의 문안은 이미 **법령 근거까지 박힌 템플릿**(`src/lib/complaintText.ts`)이라 LLM이 더하는 가치는 작고 환각 위험은 크다. **발표 전에는 LLM을 런타임에 붙이지 않고, 쓰더라도 「미리 생성해 JSON」 정도를 권한다.**
- 서버는 LLM과 상관없이 실시간 버스 중계 때문에 이미 필요하다. **Cloudflare Workers 무료 한 개**로 버스 중계와 (나중에) LLM 프록시를 함께 맡기는 것을 추천한다.

## ⑥ 적용할 만한 기능과 위험
현재 `buildComplaintText`는 템플릿이다. 위치·유형·현황·실측값·사진 수·관련 제보 수·검증 상태·소관 기관 후보를 채우고, 관련 법령 기준(`criteriaFor`)은 korean-law MCP로 확인한 값을 코드에 고정해 둔 것이다. 즉 **사실과 법령 인용은 이미 결정론적으로 안전**하다. LLM이 더할 수 있는 건 문장 다듬기 정도이고, 잘못 쓰면 지어낸 조문·기관명이 들어갈 위험만 늘어난다.

| 기능 | 가치(솔직한 평가) | 위험 | 필요한 안전장치 |
|---|---|---|---|
| 민원 문안 다듬기·쉬운 말 | 낮음~중간. 시민이 쓴 「현황」 문장을 정중하게 다듬는 정도 | 법령·수치·기관을 새로 만들 수 있음 | 템플릿의 법령 줄은 LLM이 못 건드리게 분리, 다듬은 결과는 「AI 보조 초안 — 확인 필요」 표시, 시민이 읽고 보내기 |
| 제보 유형 자동 분류 | 중간. 입력 부담을 줄일 수 있음 | 오분류 | 제안만 하고 사용자가 확정, 근거 문장 표시 |
| 중복 제보 판단 보조 | 낮음. 이미 거리(100m)·유형으로 판단 중 | 서로 다른 장소를 같다고 판단 | 거리 규칙이 우선, LLM은 참고만 |
| 사진 설명 | 낮음. 비전 모델 필요(Kanana-v, EXAONE 4.5가 있으나 호스팅·사양 문제) | 사진에 없는 내용 서술 | 사람이 수정, 사진은 외부 전송 동의 필요 |
| 분기 보고서 요약 문장 | 중간. 집계 숫자를 문장으로 | 숫자를 틀리게 서술 | 숫자는 코드가 채우고 LLM은 연결 문장만, 또는 JSON 미리 생성 후 검토 |
| 소관 기관·법령 안내 | **쓰지 말 것** | 환각 위험 최대 | 기존 `criteriaFor`·기관 후보 데이터만 사용 |

## ⑦ 사용자에게 확인할 것
1. 발표에서 LLM을 **실제로 보여 주고 싶은가**, 아니면 「AI 보조 작성은 이후 단계」로 설명만 해도 되는가. (후자면 이 조사 결과는 보관만 해도 됨)
2. 앱인토스 출시를 정말 할 것인가. 한다면 EXAONE NC 계열은 제외하고 Kanana(표기 의무 포함)를 기준으로 삼는 것에 동의하는가.
3. LG·Kakao에 상업 이용·API 이용 가능 여부를 직접 문의할 의향이 있는가(확인 안 된 부분이 많음).
4. 서버비를 월 얼마까지 낼 수 있는지(아래 ⑧은 월 1만 원 안팎 이하를 기준으로 작성).
5. 사진·제보 내용을 외부 AI 서비스로 보내도 되는지(개인정보·초상 포함 가능성).

### 8-3. 최소 구성 예시(텍스트)
```
브라우저(GitHub Pages: https://<계정>.github.io/wheel-map/)
   │  HTTPS, JSON, Origin 헤더 포함
   ▼
프록시(Cloudflare Worker)
   ├─ CORS: Origin이 Pages 도메인(과 로컬 개발 주소)일 때만 허용
   ├─ 인증/한도: IP·세션당 분당 N회, 하루 총량 상한(남용 방지), 입력 길이 제한
   ├─ 캐시: 같은 정류소 25초 등(버스), 같은 입력 재호출 방지(LLM)
   ├─ 비밀 변수: BIS 키, TMAP 키, (LLM 키) — 코드·저장소에 없음
   ├─ 로그: 요청 본문·좌표·사진·민원 문구를 기록하지 않음(상태 코드·시간·경로만)
   ▼
 /arrive, /line   → 광주 BIS(기존 provider.ts 규격 그대로)
 /llm (선택)      → 외부 LLM API 또는 자체 모델 서버(실패하면 클라이언트가 템플릿으로 대체)
```
- 앱은 서버 응답이 실패해도 동작하도록(스냅샷·템플릿 폴백) 유지한다. 시연 중 끊김을 막는 가장 중요한 장치다.
- 앱인토스: 공식 시작 문서상 **서버는 선택**이며 SDK만 쓰면 서버 설정을 건너뛸 수 있다. 서버 간 통신(토스 로그인·결제·푸시)은 mTLS로 보호된다고 안내한다. iframe 금지는 확인됨. **11-11 Aside 확인**: API는 HTTPS만(라이브에서 HTTP 차단, `wss://`만), CSR/SSG만; 외부 서버는 CORS에 미니앱 Origin(`https://<appName>.apps.tossmini.com` 등) 등록 필요; 생성형 AI는 첫 사용 시 고지·결과물 AI 라벨 표시 의무(위반 시 최대 3,000만 원 과태료), AI 채팅은 안전 필터 등 추가 요건. 외부 AI API 호출 허용 여부·도메인 화이트리스트는 Aside로도 확인 안 됨. 상세는 `docs/AI_검색창_도입_조사.md` 부록.

### 8-4. 단계별 구축 순서
| 단계 | 할 일 | 비용 |
|---|---|---|
| 오늘 할 수 있는 최소 | Cloudflare Workers 한 개로 `/arrive`·`/line`만 구현해 버스 실시간 연결(`VITE_BUS_RELAY_URL`). 키는 Workers 비밀 변수. CORS는 Pages 도메인만. LLM은 아직 붙이지 않음 | 무료 |
| 발표 전 | 호출 한도·캐시·실패 시 스냅샷 폴백 점검, 로그에서 개인정보 제외, 인터넷 끊김 리허설. LLM을 보여 줄 거면 ① 미리 생성 JSON(검토 후 포함)으로 한정 | 무료(여유가 없으면 월 $5) |
| 출시 대비(앱인토스) | 라이선스 정리(EXAONE NC 제외, Kanana 표기), 앱인토스 서버·보안 요건 확인, 제보 저장이 필요하면 DB와 개인정보 처리방침 설계, 상업 이용 해석에 맞는 호스팅 약관(예: Vercel Hobby 비상업 제한) 점검 | 월 소액~ 확인 안 됨 |

**사용자가 직접 해야 하는 일(조사자는 하지 않음)**: Cloudflare 계정 가입(무료), 필요 시 결제수단 등록(Workers Paid), BIS·TMAP 키를 Workers 비밀 변수로 직접 입력, (LLM을 쓸 경우) FriendliAI 등 제공자 가입·키 발급, Oracle Cloud 가입(카드 필요 여부 확인 후), 앱인토스 개발자 가입, LG·Kakao 상업 이용 문의.

### 8-5. 예산 기준 판단(「공짜면 최고, 소액이면 감수」)
- **무료로 충분한 것**: 버스 실시간 중계, 키 숨기기, 미리 생성 JSON. Workers 무료(하루 10만 요청)는 발표·시범 규모에 넉넉하다.
- **소액(월 $5 안팎)을 내면 좋아지는 것**: Workers Paid로 넘어가면 한도 상향(수치 확인 안 됨)과 무료 한도 소진 시 중단 위험 감소. 다만 발표 규모에서는 체감 이득이 작다.
- **소액으로 해결되지 않는 것**: 모델 자체 호스팅(GPU는 시간당 달러 단위, 월 환산 시 예산 초과). 한국어 호스팅 모델 API의 가격은 확인 안 됨.
- **판단**: 서버는 **무료 Workers로 충분**. LLM은 **돈을 내도 이득이 작고**(문안은 이미 템플릿) 라이선스·환각 부담이 있으므로, 발표 전에는 붙이지 않거나 미리 생성 JSON으로만 한다.
