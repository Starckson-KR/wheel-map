## 2. 메타 "에스터릭스" = Astryx (추정, 높은 확률)

발음과 블로그 마스코트 배경(별표 = asterisk)이 일치한다. 사용자 발언과의 일치는 추정이다.

- 이름: Astryx. Meta 공개 디자인시스템, 베타.
- 저장소: https://github.com/meta/astryx (facebook/astryx 주소도 같은 저장소). 사이트 https://astryx.atmeta.com/ , 발표 https://astryx.atmeta.com/blog/introducing-astryx (2026-06-18), 구조 설명 https://astryx.atmeta.com/blog/how-astryx-works , 보도 https://www.infoq.com/news/2026/09/meta-astryx-design-system
- 라이선스: MIT (상업·재배포 가능).
- 현황: 스타 약 2.8만, 저장소 생성 2026-01-09, 최근 push 2026-11-15. npm `@astryxdesign/core` 0.7.16 (2026-11-14).
- 구성: 접근성 컴포넌트 150개 이상, 테마, 다크모드, 템플릿, CLI. 미리 컴파일된 CSS + 타입 지정 React 컴포넌트.
- 우리 스택: Vite 안내가 README에 있고 빌드 플러그인 불필요. **React 19 이상 필수**(우리 19.3.1 이라 충족). peer: `@stylexjs/stylex ^0.19.0`.
- 도입 비용: `npm i @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex`, CSS import + 테마 Provider. core npm unpacked 약 31MB(트리쉐이킹 후 번들 크기는 측정 안 됨). 0.x 베타라 API 변경 가능. 차트는 canary에서만(보도 기준).
- 판정: 가능하나 **전면 도입은 내일 리뷰 전에는 비권장**. 기존 UI를 다 갈아야 하고, 번들·스타일 충돌 위험이 있다. 참고로 둘러보거나 일부 접근성 컴포넌트만 시험하는 정도가 적당. 모바일 지도 앱에 맞는지(번들 크기)는 확인 안 됨.
- 기타 Meta 관련: StyleX(https://github.com/facebook/stylex , MIT, `@stylexjs/stylex` 0.19.2 런타임 약 330KB unpacked, Vite는 `@stylexjs/unplugin` 필요, Babel 기반 설정). 단독 도입은 비용 대비 이득이 작음. 이 밖에 최근 공개된 Meta UI 오픈소스는 더 찾지 못함.

## 내일 리뷰 전 추천

1. vaul(바텀시트): 설치와 적용이 쉽고 드래그 제스처가 토스 시트 느낌에 가깝다. 단, 현재 시트 구현이 있으면 교체 비용 대비 이득을 먼저 볼 것.
2. motion(LazyMotion): 스프링 전환을 5KB대로 얻는다.
3. Tossface: 라이선스 전문 동봉 조건만 지키면 이모지 통일에 쓸 수 있다.
- Astryx는 흥미롭지만 베타·전면 교체 비용 때문에 내일 전에는 보류, TDS·Figma 키트·Toss Product Sans는 불가.
