# 북구동행지도 발표 시연 시나리오

> 작성 2026-11-10. 개발 서버(`localhost:5173`, 빌드 5a7c552)에서 클릭 순서를 직접 따라 해 보고 쓴 것이다. 따라 해 본 곳은 "확인함", 못 해 본 곳은 "미확인"으로 적었다.
> 발표 10분 안팎(시연 포함). 시민 화면은 휴대폰(미러링) 또는 PC 브라우저 모바일 폭(375px), 행정 화면은 PC 폭.
> 주소는 배포 `https://starckson-kr.github.io/wheel-map/` 뒤에 붙인다. 예: `…/wheel-map/#/map?go=route`. 같은 해시로 다시 이동하면 화면이 새로 안 그려질 수 있으니, 이동 뒤 어색하면 새로고침(저장소는 유지됨)한다.
> 시연 데이터는 가상이다(1장 대본에서 한 번 밝힌다). 사진은 시연 데이터에 없다. 사진이 필요한 곳은 2장(새 제보, 직접 올림)뿐이고, 조치 전후 사진 비교 화면은 보여 줄 수 없다.

**시연 계정(시연 도구 > 누구로 볼까요)**: 시민 A(제보자), 시민 B·C(확인·재확인), 검증자(동행 점검단), 담당 공무원(데모). 실제 로그인이 아니다. 시연 도구 버튼은 홈에는 없고, 지도·민원신고·내 정보·혜택알림 탭과 행정 화면 위쪽에 있다.

## 예상 질문과 답변

1. **국민신문고·안전신문고와 무엇이 다른가요? 중복 아닌가요?**
   대체가 아니라 연계입니다. 신문고는 접수와 처리 창구이고, 이 앱은 접수 전에 시민 검증과 중복 확인, 경로 단위 묶음을 하고 접수 후에는 처리 결과를 시민이 다시 확인합니다. 접수는 공식 창구에서 하시도록 링크를 안내합니다.
2. **외부 접수 연동은 실제로 되나요?**
   현재 공개된 접수·조회 API는 확인되지 않았습니다. 그래서 공식 창구 링크 안내와 접수번호 직접 기록 방식으로 설계했고, 화면의 모의 접수·모의 조회는 시연입니다. 관계기관 문의는 아직 하지 않았습니다.
3. **제보가 허위이거나 장난이면 어떻게 하나요?**
   다른 시민 2명 이상의 확인 또는 검증자의 현장 확인이 있어야 검증됩니다. 반려·중복 합침은 점수에서 제외하고, 점수는 검증된 기여에만 지급합니다.
4. **소관 기관이 잘못 표시되면요?**
   소관 기관·조문은 확인되지 않은 것은 "확인 필요"로 표시합니다. 후보 안내이며 최종 접수는 사용자가 공식 창구에서 합니다. 소관이 확정되지 않은 기관은 북구청 문의가 필요한 부분입니다(아직 문의 전).
5. **개인정보는요?**
   사진의 얼굴·번호판을 가리도록 안내하고(자동으로 가려 주지는 않음), 사진은 기기에서 축소하며 촬영 위치 같은 부가 정보를 지웁니다. 이동 궤적은 저장하지 않고 제보 지점만 다룹니다. 이번 시연은 브라우저 안에만 저장되는 프로토타입입니다.
6. **○△X 기준은 누가 정했나요?**
   팀 내부 기준안입니다. 보도 유효폭 2m 이상 ○, 1.2~2m △, 1.2m 미만이나 막힘 X 같은 수치로, 휠체어 이용 당사자 인터뷰 후 수정할 예정입니다(미반영).
7. **랭킹이 사람들을 경쟁하게 만들지 않나요?**
   랭킹은 보조 기능으로 두었고, 검증된 기여만 세며, 제보가 적은 곳이 안전하다는 뜻이 아니라는 안내를 같이 보여 줍니다. 동 단위 합계만 보여 주는 지역 화면도 있습니다(개인 순위 없음).
8. **정책에는 어떻게 쓰이나요?**
   부서별 현황, 분기 보고서, 우선순위, 개선계획·예산 연결에서 개선 근거로 활용할 수 있습니다. 금액과 사업은 담당자가 입력하며 앱이 정하지 않습니다.

**알려진 문제**
1. **"대안 없음" 조합이 없다.** 현재 시연 3쌍(학교 쪽문→전대치과병원, 한화꿈에그린 정류장→전대치과병원, 북구청 옆 정류장→전대치과병원)은 확인 결과 각각 "주의"/"어려움→돌아가는 길 주의"/"주의"이고 "대안 경로 없음"이 나오는 쌍이 없다. 옛 11장의 "후문 원룸촌→전대치과병원" 쌍은 없다. 대안: ① 이 시나리오처럼 두 번째 쌍으로 "짧은 길 X, 우회 가능"을 보여 준다 ② 후문 원룸촌 출발 쌍을 새로 저장해 "대안 없음"을 만든다(길찾기 호출 한도 확인 필요, 사용자 결정).
