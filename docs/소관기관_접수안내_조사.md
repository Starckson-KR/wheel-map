## ⑥ 확인하지 못한 것 (우선순위순)

1. **용봉동 구체 도로의 관리 구분**: 어느 노선이 광역시도(시)이고 어느 쪽이 구도·20m 미만인지 → 도로대장·노선 고시 또는 북구청 건설과 도로관리팀 문의.
2. **버스정류장 시설·노면의 구/시 소관 부서**, 신호기·음향신호기 담당 부서.
3. **민간 건물 편의시설 미비 접수처**: 편의증진법상 시설주관기관(구청장)의 실제 담당 과(건축과/장애인복지과 등)와 대상시설 범위(시행령 별표).
4. **전남대 광주캠퍼스** 시설 담당 부서·접수 방법 (누리집 접속 오류).
5. **용봉동 행정복지센터** 업무·번호.
6. 킥보드 방치 단속 담당(구/경찰/운영업체), 입간판의 광고물 해당 여부, "불법주기" 의미.
7. 도로교통법 조문의 **현행본 대조**(조회 서버가 시행예정본 반환), 폐기물관리법·옥외광고물법 조문(미조회).
8. 시 조직도 각 과의 업무분장, 도로관리사업소 관할, 사무위임 조례 별표의 부서명과 현 조직 일치 여부.

10. 시·구 조직 개편 가능성(구청 조직 개편안, 시 청사 재배치 논의 보도)으로 부서명이 변할 수 있음 → 앱에는 "과 이름"을 바꿀 수 있는 데이터(agencies.json)로 두고 발표 전 재확인.
