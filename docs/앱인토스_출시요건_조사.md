# 앱인토스 출시 요건 조사

조사일 2026-10-28. 공식 문서(developers-apps-in-toss.toss.im)를 읽기만 했고, 로그인·신청은 하지 않았다.
표기: **확인** = 공식 문서에 명시. **확인 필요** = 문서에 없거나 불명확(콘솔·채널톡으로 문의).
문서 요약 도구를 거쳤으므로 중요한 값(심사 기간·사업자 요건)은 신청 전에 원문을 한 번 더 본다.

## ① 한 줄 결론

**조건부 가능, 지도 때문에 어려움.** 웹(Vite+React)은 SDK만 얹어 올릴 수 있고 비용도 없다. 하지만 **카카오맵 JS 키를 토스 안에서 쓰는 것은 카카오 측이 막고 있어(2026-10-26 답변) 지도 엔진 교체가 사실상 필수**다. 지도는 이 앱의 핵심이라 가장 큰 변경이다.

## ② 항목별 확인 사항

### 2. 외부 SDK·도메인·권한·저장소
| 항목 | 내용 | 상태 |
|---|---|---|
| 카카오맵 JS SDK | 앱인토스 공식 문서에는 외부 지도 스크립트 허용·금지 언급 없음. **카카오 데브톡 답변(2026-10-26): 같은 서비스에서 여러 개발자 앱을 쓸 수 없고, 토스 안에서 지도가 필요하면 "해당 플랫폼 제공자에게 요청"하라고 안내.** 앞선 답변들도 입점사 앱의 키는 토스 인앱에서 못 쓴다는 취지. 사용자 키(`MAP`)로 `*.apps.tossmini.com`을 도메인 등록하는 방식은 막힐 가능성이 높음 | 토스 쪽 허용 여부 확인 필요 / 카카오 쪽은 사실상 불가로 봄 |
| 허용 도메인·CSP | 문서에 CSP·스크립트 허용 목록 없음. 외부 서버 통신 시 서버 CORS에 미니앱 origin 추가 필요 | CSP 확인 필요, CORS 확인 |
| 외부 코드 | `eval` 등 외부 코드 실행 금지. 외부 콘텐츠를 토스 도메인 밖에서 렌더링하는 이동 금지 | 확인 |
| HTTPS | 모든 API는 HTTPS, WebSocket은 wss만 | 확인 |
| 위치 | `Device.getLocation`/`getCurrentLocation`(SDK) 권장. `permissions`에 `geolocation`(`access`) 선언. 권한 확인·요청 API 있음. `navigator.geolocation`은 "대부분의 표준 웹 API 지원"이라 되나 보장 문구는 아님. 사용자 동의 후 요청, **거부해도 나머지 기능은 정상 동작해야 함** | 확인(SDK), navigator 확인 필요 |
| 카메라·사진 | `openCamera`(결과 dataUri/base64). `permissions`에 사진 `read` 선언 예시 있음. `<input type="file">` 동작 여부 문서에 없음 | 확인 필요 |
| 저장소 | 권장은 SDK `Storage`(문자열, 앱 삭제 시 삭제, AsyncStorage 금지). localStorage·IndexedDB는 WebView origin 범위에서 쓸 수 있으나 **iOS IndexedDB는 7일 미사용 시 삭제**. QR 테스트와 실서비스는 origin이 달라 데이터 공유 안 됨 | 확인 |
| 쿠키 | iOS 13.4+ 서드파티 쿠키 차단 | 확인 |

### 5·6. 배포 순서(GitHub Pages 먼저)
- GitHub Pages(`/wheel-map/` 하위 경로, 해시 라우팅)와 앱인토스(`<appName>.apps.tossmini.com` 루트)는 **호스팅이 완전히 별개**라 충돌하지 않는다. 먼저 올려도 문제없다.
- 같은 소스를 쓰되 **빌드는 둘로 나누는 것이 안전**: `base`(`/wheel-map/` vs `/`), DevBadge, 지도 엔진, 키 처리, 시연 도구가 다르다. 환경변수(`VITE_TARGET=pages|toss`)로 분기하는 방안을 권장.
- 같은 빌드를 그대로 재사용 가능한지는 `base`가 `./`(상대 경로)면 가능성이 있으나 문서로 확인되지 않았다 → 확인 필요.
- GitHub Pages 쪽을 카카오맵으로 먼저 내보내도 되지만, **앱인토스용은 지도 엔진을 추상화**(어댑터)해 두는 편이 재작업이 적다.

## ③ 우리 앱 변경 목록 (우선순위)

**P0 — 막히는 것**
1. **지도 엔진 결정**: 카카오맵은 토스 안에서 불가로 본다(카카오 답변). 대안 후보(약관·키·토스 내 동작은 아직 미확인): OpenStreetMap 타일 + Leaflet/MapLibre(타일 서버 이용 정책·출처 표기 확인), 네이버 지도, TMAP 지도 SDK(경로 API는 이미 사용 중). 어느 쪽이든 `KakaoMap.tsx`·`kakao.ts`·지오코더·장소 검색을 분리된 계층으로 바꿔야 함. 장소 검색·지오코딩은 미리 받은 JSON 또는 서버 중계 필요.
2. **카카오에 직접 확인**: 토스 인앱 지도 사용이 가능한 제휴 경로가 있는지(데브톡 답변은 "플랫폼 제공자에게 요청"). 토스 쪽에도 "외부 지도 SDK 허용 여부"를 채널톡으로 문의.
3. **서비스 유형 확인**: 시민 제보·민원 연결 서비스가 입점 가능한 카테고리인지(채널톡 사전 상담).

**P1 — 기능·정책**
4. **모의 접수(데모) 모드**: 출시판은 `COMPLAINT_MODE=link`만 두고 `mock`·시간 앞당기기·시연 데이터·시연 사용자 전환을 제거(또는 빌드에서 제외). 외부 접수 링크는 보조로, 앱 안에서 문안 복사·접수번호 기록까지 완결되게.
5. **로그인/사용자 구조**: 시연 사용자 전환 대신 토스 로그인(사업자 필요) 또는 비로그인 구조 중 선택. 개인이라면 비로그인 + 기기 저장 위주로 단순화.
6. **저장소**: 제보 데이터가 localStorage/IndexedDB에만 있어 iOS 7일 미사용 삭제·기기 변경 시 소실. SDK `Storage`로 옮기거나 서버 연동 검토. 사진은 `openCamera` 또는 파일 입력 동작 확인 후 결정.
7. **위치 권한**: `geolocation` 권한 선언, 동의 후 요청, **거부해도 지도·목록 정상 동작**(현재 위치 실패 처리 확인).
8. **실시간 저상버스(7단계)**: 브라우저에 키를 못 넣으므로 자체 서버(중계) 필요. 서버는 HTTPS, CORS에 `https://<appName>.apps.tossmini.com`·`.private-apps.tossmini.com` 등록. 서버 없이 가려면 미리 받은 정적 JSON까지만.
9. **개인정보**: 제보 사진 GPS 제거·얼굴·번호판 가림, 개인정보 처리방침, 위치정보 수집 동의 문구 준비.

**P2 — 구조·디자인**
10. **빌드 분기**: `base` `/` 또는 상대 경로, 해시 라우팅 유지 여부 확인, 환경변수 분기.
11. **DevBadge**: `VITE_SHOW_DEV_BADGE=false`로 끄고 출시 빌드에서는 코드째 제거.
12. **내비게이션**: 앱 자체 상단 바와 토스 내비게이션 바 중복 정리(뒤로가기 중복 금지, 첫 화면 뒤로가기 시 종료).
13. **TDS**: 필수 아님. 선택사항으로 일부 컴포넌트 교체(React 19 vs TDS의 react ^18 요구 확인 필요). 직접 만든 CSS 유지해도 되나 디자인 가이드(해요체·다크패턴 금지) 준수는 필수.
14. **Pretendard**: CDN 대신 번들 포함 권장(외부 CDN 로딩 이슈가 출시 후 점검 항목에 있음).
15. **SDK 설치**: `@apps-in-toss/web-framework`, devtools, `apps-in-toss.config.ts`(`appName`은 콘솔과 일치).
16. **번들 용량**: 공공데이터 JSON·사진 포함 시 100MB 이하 확인(현재 사진은 배포 제외).

## ④ 사용자가 해야 할 일

1. 토스 앱 본인 계정으로 앱인토스 콘솔 가입, 워크스페이스 생성(대표관리자 1인, 만 19세 이상). 팀원 초대는 이메일.
2. **사업자 등록 여부 결정**: 없어도 출시는 되나 토스 로그인·결제·광고는 못 씀. 우리 기능에 필요한지 판단.
3. 카카오(데브톡/고객센터)와 토스(채널톡 https://apps-in-toss.channel.io/)에 문의: ① 토스 인앱에서 카카오맵 사용 가능한 방법 ② 외부 지도 SDK 허용 여부 ③ 시민 제보·민원 서비스의 카테고리·심사 가능 여부 ④ 시연용 기능 허용 범위.
4. 지도 엔진 방향 승인(P0-1).
5. 앱 이름(`appName`, 변경 불가)·로고(600×600)·설명·지원 이메일 준비, 개인정보 처리방침 초안 승인.
6. 팀원 B 확인 사항 등 기존 대기 항목은 그대로 유지.
